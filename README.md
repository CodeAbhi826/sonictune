# SonicTune

**Still in development.**

Licensed under GPL-3.0-or-later.

## Features

- **SponsorBlock** — auto-skips sponsor, intro, outro, self-promo and
  off-topic segments inside YouTube Music tracks (optional, on by default).
- **YouTube Music playback** — native streaming via ytmusicapi with an
  automatic yt-dlp fallback that retries with `--force-ipv4`/`--geo-bypass`
  and skips to the next track when a video is unavailable.
- **Material You dynamic theming** — the accent palette is extracted from
  the current album artwork.
- **Sleep timer**, **Last.fm scrobbling**, **keyboard shortcuts**, and a
  **secure (encrypted) token store** for sign-in credentials.
- **Local library scanning** with audio metadata extraction.
- Desktop integration: **MPRIS**, system tray, Discord Rich Presence, and
  synced lyrics.
